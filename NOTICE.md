# Notices

This project implements an adapter around Google's official Antigravity CLI ACP
runtime (`agy acp`). It does not include or redistribute Google software.

Protocol behavior was validated against the public Agent Client Protocol and by
using a local fake ACP process. Design references include these MIT-licensed
community projects:

- DylanLIiii/opencode-antigravity-bridge
- yulong-ge/magpie-antigravity-acp

No source file from those projects is intentionally copied wholesale. If future
changes incorporate substantial portions, preserve their MIT copyright and
license notices as required.
